食べたものと動いた分のバランスを。

Bodyscope は歩数を数え、ウォーキングとランニングを記録し、食事を記録して、毎日のエネルギー収支（摂った分と消費した分）を表示します。すべてはあなたのスマートフォンの中に残ります。

バランスのとれた一日のために

片側に食事、もう片側に運動、そして真ん中にあなた自身のプロフィール。だから数値は平均的な誰かではなく、あなたに合わせたものになります。

食事と食品

約 900 品目の初期リストから食事を組み立てるか、USDA と Open Food Facts のデータベースを検索できます。カロリーと栄養素は自動で合計されます。お皿を撮影すれば、Claude AI が食品を認識することもできます（ご自身のキーが必要）。

歩数計

一日中バックグラウンドで歩数を数えます。1 日の目標歩数と、ウォーキング・ランニング用のあなた自身の歩幅を設定できます。

ウォーキングとランニング

距離、時間、ペースとともにウォーキングやランニングを記録し、OpenStreetMap の地図でルートを確認、途中で音声案内も受けられます。

その他の運動

サイクリング、水泳、筋トレ、ヨガ、ガーデニングなど多くの運動を記録できます。消費エネルギーは体重と運動の強さから計算されます。

毎日の収支

基礎代謝、歩数、ランニング、運動から、摂取カロリーと消費カロリーを比べます。目標体重を設定すれば、1 日に何カロリーで到達できるかがわかります。

グラフと履歴

日ごと・週ごとに振り返れます。1 日の食事、期間ごとの栄養素、ウォーキングとランニングの履歴。

計算ツール

年齢、性別、身長、体重、活動量を使う BMI 計算機とカロリー計算機。

自分で管理できるバックアップ

データを好きなフォルダーに、手動で、または毎日・3 日ごと・毎週の自動でバックアップし、新しいスマートフォンで復元できます。

19 言語、6 テーマ

Bodyscope をあなたの言語で使い、明るい色から暗い「月明かり」テーマまで、好きな配色を選べます。

使い方

設定は 3 つだけ。あとは Bodyscope がその日の数値を記録します。

あなたについて入力

生年月日、性別、身長、体重を入力します。Bodyscope が安静時に体が必要とするエネルギーを計算します。

食べたものを記録

食品リストから各食事を追加するか、リストにないものは食品データベースで検索します。

あとは動くだけ

歩数カウントを一度オンにすれば、一日中歩数が数えられます。ウォーキングやランニングを始めたり、他の運動を記録したりして、その日の収支を確認しましょう。

データはあなたのスマートフォンに

Bodyscope はあなたの端末の中で動きます。アカウント作成は不要で、プロフィールや食事、運動をサーバーに送る隠れた仕組みもありません。

  • アカウントもログインも不要インストールしてすぐ開始。登録は不要です。
  • 広告なし、トラッキングなしアプリに広告や分析のコードは含まれていません。
  • 外に出るのは検索と写真だけオンラインの食品データベースを検索するとき、そのサービスに送られるのは検索語だけです。分析を選んだ食事の写真は、あなた自身のキーで Anthropic に送られます。
  • バックアップの保存先はあなたが選ぶスマートフォン内のフォルダー、SD カード、またはご自身のクラウドフォルダー。

よくある質問

特によくいただく質問です。

Bodyscope は有料ですか？

いいえ。Bodyscope は無料で、広告もアプリ内課金もありません。

どのスマートフォンで動きますか？

Android 6.0（Marshmallow）以降のすべての Android スマートフォンで動きます。

このサイトからどうやってインストールしますか？

下のボタンで APK ファイルをダウンロードし、スマートフォンで開きます。初回は、ブラウザーやファイルマネージャーからのアプリのインストールを許可するよう Android が求めます。Bodyscope は新しいバージョンを自分で確認します（このアプリについて → アップデートを確認）。

新しいスマートフォンにデータを移すには？

メニューのデータのバックアップを使い（または設定で自動バックアップをオンにし）、バックアップファイルを新しいスマートフォンにコピーして、そこでデータの復元を使います。

一部の言葉が自分の言語ではなく英語です。なぜですか？

あなたの言語の翻訳がまだ完全ではないのかもしれません。ほとんどの翻訳は最初に自動で作られたため、間違っているものもあるかもしれません。ご協力いただけると嬉しいです。ぜひご連絡ください。

機能の提案や問題の報告はできますか？

ぜひどうぞ。bodyscope.team@gmail.com にメールするか、アプリのこのアプリについて → 作者にメールをご利用ください。すべてのメッセージに目を通します。

新しい食品を追加するには?

方法は2つあります。どちらの方法でも食品は食品ファイルに追加され、すべての食事で使えます。

1. 食品ファイルに直接追加する

  1. メニュー(☰)を開き、ファイルの管理 の 食品 をタップします。
  2. 右上の ⋮ をタップし、レコードを追加 を選びます。
  3. 食品名、量とその単位(例: 100 gr、1 切れ)、その量の炭水化物・たんぱく質・脂質・カロリーを入力し、同意する をタップします。

2. 食事を作成しながら: 複合食品

  1. 1日の食事 で右下のボタンをタップし、食事の詳細を追加 を選びます。
  2. + をタップし、材料をそれぞれの量で追加します。
  3. 食品を構成する材料にチェックを入れ、左下のメニューボタンをタップして 選択項目から複合食品を作成 を選びます。
  4. 食品に名前を付けて 同意する をタップします。食事の中の材料は新しい食品に置き換えられ、その食品は食品ファイルにも追加されます。

画面写真は英語表示のアプリです。

「写真から食事」はどのように動きますか？

Bodyscope は、Anthropic の AI である Claude を使って、写真からお皿の食品を認識できます。この機能は任意で、ご自身の Anthropic API キーが必要です。

使い方

  1. 1日の食事 で右下のボタンをタップし、食事の詳細を追加 を選びます。
  2. カメラボタン（写真から食事）をタップし、写真を撮る または ギャラリーから選ぶ を選びます。
  3. Claude が見つけた食品を、推定の重さとカロリー付きで一覧にします。間違っているもののチェックを外し、食事に追加 をタップします。
  4. 食事内の食品をタップして量を修正し、いつもどおり食事を保存します。

キーの入手方法

  1. console.anthropic.com でアカウントを作成し、クレジットを購入します。
  2. API キーを作成してコピーします。
  3. Bodyscope でメニュー（☰）を開き、設定 › 食事の設定 で Claude APIキー をタップして貼り付けます。

料金とプライバシー

Anthropic は写真ごとにあなたのキーに課金します。現在の価格で 1 枚あたり約 0.001〜0.002 米ドル、つまり 100 枚で約 10〜20 セントです。クレジットは前払いで、約 5 米ドルから購入できます。Bodyscope 自体は無料です。

写真はこの機能を使ったときだけ、スマートフォンから Anthropic へ直接送られます。間に Bodyscope のサーバーはありません。キーはアプリの設定に保存され、設定はバックアップにも含まれるため、バックアップは他人に渡さないでください。
