Bodyscope

隐私政策

最后更新：2026 年 11 月 5 日

Bodyscope 是 Yannis Tzavellas（Hyperlog）开发的应用。简而言之：你输入的内容都留在你的手机上。没有账户、没有广告、没有分析，我们也没有任何收集你数据的服务器。本页说明少数几种会有内容离开你手机的情况，并且只在你使用相应功能时才会发生。

留在你手机上的内容

你的个人资料（如年龄、性别、身高和体重）、餐食和食物、步数、步行和跑步记录及其路线，以及应用的设置（包括你添加的 Anthropic API 密钥），都只保存在你手机上的应用存储中。我们看不到这些内容。

权限及其用途

  • 位置：用于记录步行或跑步的路线和距离，仅在记录期间使用。期间 Android 会一直显示通知。
  • 运动传感器和后台运行：用于全天计步；计步器开启时会显示通知。
  • 通知：用于计步器以及正在记录的步行和跑步。
  • 相机和照片：仅限你为“拍照记餐”或“拍照新建食物”拍摄或选择的那张照片。应用使用 Android 自带的相机和照片选择器，因此看不到其他照片。
  • 麦克风：应用不会请求此权限。语音搜索使用手机的语音服务（见下文）。
  • 存储：用于在你选择的位置写入和读取备份及导出文件。
  • 网络：仅用于下一节所列的功能。

哪些内容会离开你的手机，以及何时

不会在后台发送任何关于你的信息。只有在你使用以下功能之一时，数据才会离开手机：

  • 在线搜索食物：你搜索的词语会发送到 USDA FoodData Central 或 Open Food Facts。
  • “拍照记餐”和“拍照新建食物”：你选择的照片会使用你自己的 API 密钥，从手机直接发送到 Anthropic，由 Anthropic 的人工智能 Claude 描述照片中的食物。Anthropic 按其自身的条款和隐私政策处理照片，并向你的 Anthropic 账户收费。中间没有 Bodyscope 的服务器，我们也不保留任何副本。
  • 语音搜索：点按麦克风时，手机的语音识别服务（通常是 Google 的）会把你说的话转换为文字。
  • 地图：步行和跑步的地图来自 OpenStreetMap 的瓦片服务器，这些服务器能看到所显示的区域。
  • 检查更新：仅限从本网站或 GitHub 下载的版本，Google Play 版本没有此功能。应用会向我们的更新服务器询问最新版本号，不会随之发送任何关于你的信息。
  • 与任何网络连接一样，上述每项服务也能看到你手机的 IP 地址。

备份

备份是应用写入你所选文件夹的文件：可以在手机上、SD 卡上或你自己的云端文件夹中。备份包含你的全部数据和 Anthropic API 密钥，请妥善保管，不要外泄。我们从不会收到这些备份。

我们不做的事

  • 没有账户，也无需登录。
  • 没有广告、没有分析、没有跟踪，也不会向任何地方发送崩溃报告。
  • 我们不出售、不共享也不接收你的数据，因为这些数据从不会到达我们这里。

删除你的数据

  • 在应用中删除单条记录，或通过菜单（☰）中的“恢复出厂设置”清除全部内容。
  • 卸载 Bodyscope 会从手机上移除它的全部数据。
  • 备份会留在你保存的位置，请自行删除。
  • 如不再使用你的 Anthropic API 密钥，请在“设置”中移除，并在 console.anthropic.com 删除该密钥。

儿童

Bodyscope 面向成年人，不针对 13 岁以下的儿童。我们不向任何人收集数据，包括儿童。

本政策的变更

如本政策有变更，新版本将以新的日期发布在本页面。
