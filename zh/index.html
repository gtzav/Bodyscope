平衡一天所需的一切

一边是饮食，一边是运动，中间是你自己的资料，让数字贴合你本人，而不是一个“平均人”。

餐食与食物

从约 900 种食物的初始列表中搭配餐食，或搜索 USDA 和 Open Food Facts 数据库。热量和营养素会自动为你累加。也可以拍下你的餐盘，让 Claude AI 识别其中的食物（需要你自己的密钥）。

计步器

全天在后台为你计步，可设置每日步数目标，以及你自己的步行和跑步步幅。

步行与跑步

记录步行或跑步的距离、时间和配速，在 OpenStreetMap 地图上查看路线，并在途中收到语音播报。

其他活动

记录骑行、游泳、力量训练、瑜伽、园艺等多种活动。每项活动的能量都根据你的体重和活动强度计算。

每日平衡

根据基础需要、步数、跑步和活动，对比摄入与消耗的热量。设定目标体重，看看每天多少热量能让你达到目标。

图表与历史

回顾每天和每周：每日餐食、一段时间内的营养素，以及步行和跑步的历史。

计算器

BMI 计算器和热量计算器，会根据你的年龄、性别、身高、体重和活动量进行计算。

由你掌控的备份

把数据备份到你选择的文件夹，可手动，也可每天、每 3 天或每周自动备份，并在新手机上恢复。

19 种语言，6 种主题

用你自己的语言使用 Bodyscope，并挑选喜欢的颜色，从明亮到深色的“月光”主题。

使用方法

只需设置三件事，之后 Bodyscope 会为你记下当天的数字。

告诉它你的情况

输入出生日期、性别、身高和体重。Bodyscope 会算出你的身体在静息时需要多少能量。

记录你吃的

从食物列表中添加每一餐，列表里没有的可以在食物数据库中搜索。

动起来就行

打开一次计步，全天的步数都会被记录。开始步行或跑步，或记录其他活动，就能看到当天的平衡。

你的数据留在你的手机上

Bodyscope 在你的设备上运行。无需创建账号，也没有任何隐藏的东西把你的资料、饮食或活动发送到服务器。

  • 无需账号，无需登录安装即用，无需注册。
  • 无广告，无跟踪应用中没有广告或统计分析代码。
  • 只有你的搜索和照片会离开手机当你在线搜索食物数据库时，只有搜索词会发送给该服务。你选择分析的餐食照片会使用你自己的密钥发送给 Anthropic。
  • 备份存放在你选择的地方手机上的文件夹、SD 卡或你自己的云端文件夹。

常见问题

我们最常听到的问题。

Bodyscope 收费吗？

不收费。Bodyscope 完全免费，没有广告，也没有应用内购买。

它能在哪些手机上运行？

任何搭载 Android 6.0（Marshmallow）或更高版本的 Android 手机。

如何从本网站安装？

用下方按钮下载 APK 文件，然后在手机上打开。第一次安装时，Android 会请你允许从浏览器或文件管理器安装应用。Bodyscope 会自行检查新版本（关于 → 检查更新）。

如何把数据转移到新手机？

使用菜单中的备份数据（或在设置中开启自动备份），把备份文件复制到新手机，然后在新手机上使用恢复数据。

有些文字是英文而不是我的语言，为什么？

你的语言可能还没有完全翻译。大多数译文最初是自动生成的，所以有些可能不准确。欢迎你帮助我们：给我们写信。

我可以建议新功能或报告问题吗？

当然可以。请发邮件至 bodyscope.team@gmail.com，或在应用中使用关于 → 给作者发邮件。每条消息我们都会阅读。

如何添加新食物?

有两种方法。无论哪种,食物都会加入食物文件,可用于您所有的餐食。

1. 直接在食物文件中添加

  1. 打开菜单(☰),在“文件管理”下点按“食物”。
  2. 点按右上角的 ⋮,选择“添加记录”。
  3. 输入食物名称、数量及其单位(例如 100 gr 或 1 片),以及该数量的碳水化合物、蛋白质、脂肪和热量。点按“接受”。

2. 在组合餐食时:复合食物

  1. 在“当日餐食”中,点按右下角的按钮,选择“添加餐食详情”。
  2. 点按 +,添加各种配料及其数量。
  3. 勾选组成该食物的配料,点按左下角的菜单按钮,选择“用所选项目创建组合食物”。
  4. 为食物命名并点按“接受”。餐食中的配料会被新食物取代,新食物也会加入食物文件。

“拍照记餐”是如何工作的？

Bodyscope 可以借助 Anthropic 的人工智能 Claude，从照片中识别你盘中的食物。此功能为可选功能，需要你自己的 Anthropic API 密钥。

使用方法

  1. 在“当日餐食”中,点按右下角的按钮,选择“添加餐食详情”。
  2. 点按相机按钮（拍照记餐），然后选择“拍照”或“从相册选择”。
  3. Claude 会列出它看到的食物，并附上估计的重量和热量。取消勾选错误的项目，然后点按“添加到餐食”。
  4. 点按餐中的食物即可更正其分量，然后像平常一样保存餐食。

获取密钥

  1. 在 console.anthropic.com 创建账户并购买一些额度。
  2. 创建一个 API 密钥并复制。
  3. 在 Bodyscope 中打开菜单（☰），进入“设置 › 饮食设置”，点按“您的 Claude API 密钥”并粘贴。

费用与隐私

Anthropic 会按每张照片向你的密钥计费：按目前价格每张约 0.001–0.002 美元，即 100 张照片约 10–20 美分。额度需预先购买，最低约 5 美元。Bodyscope 本身不收取任何费用。

照片只在你使用此功能时，直接从手机发送给 Anthropic，中间没有任何 Bodyscope 服务器。密钥保存在应用的设置中，而设置也会保存在你的备份里，所以请妥善保管备份。
